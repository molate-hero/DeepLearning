                                引言

  构建一个由专家组成的小型语言模型。莎士比亚文本和 Python 代码遵循不同的模式，但都可以通
过预测下一个符号来建模。是否每个 token 都必须使用同一个前馈网络？你将构建一个混合专家（MoE）
模型，并研究它如何在控制每个 token 计算量的同时提升模型容量。
  MoE 层存储若干个 MLP，称为专家。一个经过学习的路由器会为每个 token 选择少数几个专家，
并组合它们的输出，从而将总容量与当前计算分开。专家通过联合训练学习各自的作用，而非人工指
定。Switch Transformers 在大规模场景探索了这一原理 [1]。Mixtral 8x7B 在语言、代码和多语言任务
中为每个 token 从八个专家中选择两个 [2]。DeepSeek-V3 报告总计 6710 亿参数、每个 token 激活 370
亿参数 [3]。本作业将在课程作业规模下研究这一机制。
